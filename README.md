# leeds-planning-seo

Static SEO site tracking Leeds City Council planning applications.

Served by Caddy from `output/`:

- `https://leedsplanning.home.arpa` (LAN)
- `https://leedsplanning.org.uk` (public, via the Cloudflare Tunnel in the `proxy` stack)

## Pipeline

| Script | Purpose |
|---|---|
| `ingest_careful.py` | Scrapes PlanIt application listings into `data/leeds_planning.db` (SQLite). Rate-limit aware, resumable. |
| `generate.py` | Renders the static site from the DB into `output/` using `templates/`. Emits `sitemap.xml`. |
| `pipeline.py` | Combined ingest + generate. |
| `cron.sh` | Daily entrypoint — guards against stale/hung ingests and overlapping runs, then runs ingest + generate. |

## Schedule

Run daily at 06:00 UTC by the **dev-hermes** profile cron job `leeds-planning-pipeline-daily`
(`planning-cron.sh`, resolved from `/opt/data/profiles/dev-hermes/scripts/`).

## Paths
